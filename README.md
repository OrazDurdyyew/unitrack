# UniTrack

Система учёта посещаемости студентов и утверждения отчётов для института экономики и менеджмента: замдекан отмечает посещаемость с телефона (в том числе без интернета), отчёт проходит цепочку замдекан → декан → ректорат, каждое изменение остаётся в истории, ректорат и деканы получают сводки вместо бумажных списков.

## Части репозитория

| Папка | Что внутри |
|---|---|
| `backend/` | API на Go: модульный монолит, PostgreSQL, миграции, тесты на настоящей базе |
| `web/` | Веб-панель на Vue 3 (FSD, чистый CSS, собственный набор компонентов) |
| `android/` | Android-приложение на Kotlin с офлайн-режимом (создаётся на этапе 7) |
| `infra/` | Docker Compose, nginx, окружение, установка на сервер института |
| `api/` | Контракт OpenAPI — единственный источник типов для сервера и клиентов |
| `design/` | Дизайн-токены и генератор `tokens.css` |
| `docs/` | ТЗ, проектный документ, журнал решений, статус работ |

## Быстрый старт

```bash
task setup   # установить инструменты и хуки
task dev     # поднять PostgreSQL, API и веб через docker compose
task check   # генерация, линтеры, тесты — то, что проверяет CI
```

Перед первым запуском: `cp infra/.env.example infra/.env` и задать `POSTGRES_PASSWORD`; для локальных тестов бэкенда — `cp backend/.env.example backend/.env`. Состояние работ — в `docs/STATUS.md`.
