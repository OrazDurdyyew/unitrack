# 0006. Чистый CSS, БЭМ, токены и Reka UI

Дата: 2026-11-06
Статус: принято

## Контекст

Нужна дизайн-система, которой проект владеет полностью, с единым видом веба и Android. Заказчик при обсуждении 2026-11-06 предпочёл чистый CSS без Tailwind и отказался от SCSS за отсутствием пользы. Утверждён стиль «тихий премиум» (см. `docs/design/principles.md`).

## Решение

Стили — чистый CSS в `<style scoped>` с именованием по БЭМ (`ui-button`, `ui-button__icon`, `ui-button--primary`). Все цвета, отступы, радиусы, шрифты, тени — только через CSS-переменные, которые генерируются из `design/tokens.json` в `web/src/shared/ui/tokens.css`; stylelint запрещает «сырые» значения вне этого файла. Компоненты строятся на Reka UI — безстилевых доступных примитивах (диалог, выпадающий список, табы, чекбокс) — и живут в `shared/ui` с префиксом `Ui`. Таблицы — TanStack Table как логика, разметка своя. Шрифт Inter лежит в репозитории.

## Последствия

- Плюсы: ни одного чужого стиля; полный контроль; те же токены уходят в Android; доступность из коробки через Reka UI.
- Минусы и риски: первые недели уходят на набор из 15–20 компонентов; без stylelint палитра расползётся — поэтому правило обязательно.
- Что сделать: генератор токенов в `task gen`; stylelint в pre-commit и CI.

## Отклонённые варианты

- **Tailwind CSS** — заказчик против; при БЭМ и токенах не нужен.
- **SCSS** — современный CSS уже умеет вложенность, переменные и `color-mix`; пользы недостаточно.
- **PrimeVue** — быстро, но чужие стили и тяжёлая тема поверх наших токенов.
- **shadcn-vue** — целиком на Tailwind, без него не работает; таблицы всё равно на TanStack Table.
