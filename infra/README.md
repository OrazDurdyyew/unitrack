# Инфраструктура

Вся система работает на одной машине института через Docker Compose: PostgreSQL 17, API (Go), nginx со статикой веб-панели и раздачей APK. Внешних сервисов во время работы нет (ADR 0009).

## Требования к серверу

- Linux, Docker Engine 24+ с Docker Compose v2.
- 2 ГБ ОЗУ, 20 ГБ диска (база растёт медленно: отчёты — это строки, не файлы).
- Доступ к Docker Hub при установке и обновлении (образы postgres, nginx, golang, node). Если доступа нет — образы переносятся на сервер файлом (`docker save` / `docker load`).

## Установка

```bash
git clone https://github.com/OrazDurdyyew/unitrack.git && cd unitrack
cp infra/.env.example infra/.env
# задать POSTGRES_PASSWORD (openssl rand -base64 24 | tr -d '/+=') и при необходимости порт
task infra:up
```

Проверка: `curl http://localhost:8080/api/v1/health` → `{"status":"ok","version":"..."}`; веб-панель — `http://localhost:8080`.

## Обновление

```bash
git pull
task infra:up      # пересобирает образы и перезапускает только изменившиеся контейнеры
```

Миграции базы применяются автоматически при старте API.

## Логи и состояние

- `task infra:logs` — логи API в JSON, по одной записи на запрос, с `request_id`.
- `task infra:ps` — состояние контейнеров; `api` считается здоровым только при доступной базе.
