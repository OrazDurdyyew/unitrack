# infra — правила для развёртывания

Одна машина института, Docker Compose, никаких внешних сервисов во время работы (ADR 0009).

## Что здесь

- `docker-compose.yml` — сервисы `postgres` (17-alpine, том `pgdata`, порт наружу **не публикуется**), `api` (сборка `../backend`, healthcheck `/api -healthcheck`), `web` (сборка `web.Dockerfile`: статика Vite в nginx, порт `${UNITRACK_HTTP_PORT}`, том `apk` под Android-приложение).
- `nginx/nginx.conf` — единая точка входа: статика SPA, `/api/` → `api:8080`, `/apk/` → том, кеш хешированных ассетов на год, `index.html` без кеша, заголовки безопасности.
- `.env.example` → `.env` (в `.gitignore`): `POSTGRES_PASSWORD`, порт, уровень логов, версия.
- `README.md` — установка и обновление на сервере, для администратора института.

## Правила

- Секреты только в `infra/.env`. В compose — через `${…}`; обязательные — с `:?сообщение`.
- Контейнер `api` без shell (distroless): для проверок использовать `/api -healthcheck`, не curl.
- Образы закрепляются по мажорной/минорной версии (`postgres:17-alpine`, `nginx:1.27-alpine`, `node:24-alpine`, `golang:1.26-alpine`). Обновление версии — осознанно, с проверкой `task dev`.
- Изменение `nginx.conf` проверять `task dev` и запросами к `/`, `/api/v1/health`, несуществующему пути (должен отдать `index.html`).
- Если сборка требует обращения к Docker Hub, а сети нет — образы переносятся файлом (`docker save` / `docker load`), не отключать проверки.
