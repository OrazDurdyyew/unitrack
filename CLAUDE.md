# UniTrack — правила для Claude и разработчиков

## Что это

Система учёта посещаемости студентов института экономики и менеджмента (Туркменистан). Замдекан отмечает посещаемость с телефона, в том числе без интернета; отчёт проходит цепочку замдекан → декан → ректорат; каждое изменение остаётся в истории; ректорат и деканы получают сводки. Сервер стоит внутри института, внешних сервисов во время работы нет.

- Проектный документ (источник истины по архитектуре и решениям): `docs/superpowers/specs/2026-11-06-unitrack-design.md`
- ТЗ заказчика: `docs/spec/requirements.md` (обрывается на §4.2; пробелы закрыты в проектном документе)
- Решения, которых нет в ТЗ: `docs/decisions/` (ADR)
- Внешний вид: `docs/design/principles.md`, эталон `docs/design/style-reference.html`

## Протокол сессии

**Начало.** Прочитать `docs/STATUS.md`, выполнить `git log --oneline -10`, открыть текущий план в `docs/superpowers/plans/` (если в STATUS есть «В работе»). Не переделывать то, что уже сделано — сверяться с git.

**Во время.** Решение, которого нет в ТЗ и проектном документе — записать как ADR в `docs/decisions/` (шаблон `0000-template.md`, добавить строку в индекс). Изменение `api/openapi.yaml` — отдельный коммит с префиксом `api:` и `task gen` в том же коммите. Новая зависимость — только с ADR. Тесты пишутся до кода или вместе с ним.

**Конец.** `task check` зелёный → `docs/STATUS.md` обновлён (сделано / в работе, где остановились / следующее, дата) → коммит. **Сессия, после которой STATUS не обновлён, считается незавершённой.**

## Команды

| Команда | Что делает |
|---|---|
| `task setup` | Установить инструменты Go, зависимости веба, git-хуки lefthook |
| `task dev` | Поднять PostgreSQL, API и веб в docker compose (`http://localhost:8080`) |
| `task gen` | Сгенерировать токены, бандл контракта, Go-сервер и TS-клиент |
| `task lint` | Линтеры и проверка типов всех частей |
| `task test` | Тесты всех частей (бэкенд — на настоящей PostgreSQL) |
| `task check` | То, что проверяет CI: gen → чистота diff → lint → test |
| `task api:lint` | Проверить контракт OpenAPI |
| `task backend:dev` | API локально из исходников (переменные — `backend/.env`) |
| `task web:dev` | Vite dev-сервер с прокси `/api` на `localhost:8080` |

## Структура репозитория

```
api/            контракт OpenAPI — единственный источник типов (openapi.yaml → openapi.bundle.yaml)
design/         дизайн-токены (tokens.json) и генератор tokens.css
backend/        Go: модульный монолит, PostgreSQL, миграции goose — свой CLAUDE.md
web/            Vue 3 + FSD, чистый CSS + БЭМ, Reka UI — свой CLAUDE.md
infra/          docker compose, nginx, окружение, установка на сервер — свой CLAUDE.md
android/        Kotlin, offline-first — создаётся на этапе 7
docs/           STATUS, ТЗ, ADR, дизайн, проектные документы и планы
.github/        CI: backend, web, contract (генерация совпадает с источниками)
```

## Правила кода — общие

- Документация, комментарии, коммиты, тексты интерфейса — **на русском**; идентификаторы, таблицы, файлы — **на английском** (ADR 0012).
- Коммиты: conventional commits с префиксом `feat|fix|api|docs|infra|chore|test|refactor`, текст на русском в инфинитиве («добавить…»). Маленькие коммиты, каждый проходит pre-commit. Без строк атрибуции.
- Тесты до кода или вместе с ним. Тест, который не падал до реализации, ничего не доказывает.
- Контракт сначала: эндпоинт появляется в `api/openapi.yaml` до кода (ADR 0002).
- Все даты хранятся в UTC, показываются в Asia/Ashgabat. В документах даты абсолютные.
- Предыдущая реализация eduControl не является образцом; не ссылаться на неё и не брать из неё код.

## Запреты

- Не удалять данные: студенты, группы, пользователи, отчёты — только статусы и даты.
- Не добавлять зависимостей без ADR.
- Не писать строки интерфейса в коде — только через словарь переводов.
- Не обходить линтеры (`eslint-disable`, `nolint`, `stylelint-disable`) без комментария с причиной рядом.
- Не коммитить `.env`; секреты только в `backend/.env`, `infra/.env`.
- Не использовать внешние сервисы во время работы системы (CDN, Google, облако).
- Не править сгенерированные файлы руками: `api/openapi.bundle.yaml`, `backend/internal/api/gen/*.gen.go`, `web/src/shared/api/schema.d.ts`, `web/src/shared/ui/tokens.css`.
- Не менять применённую миграцию — только новая.
