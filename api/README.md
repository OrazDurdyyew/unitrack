# Контракт API

`openapi.yaml` — единственный источник типов для сервера (Go, oapi-codegen), веб-панели (TypeScript, openapi-typescript) и Android (Kotlin, openapi-generator). Подробности решения — ADR 0002.

## Правила

1. **Контракт сначала.** Новый эндпоинт появляется в `openapi.yaml` до кода. Затем `task gen` регенерирует серверные интерфейсы и клиенты, и только потом пишется реализация.
2. **Версия в пути:** `/api/v1`. Несовместимое изменение — новая версия, старая живёт до обновления всех клиентов (Android обновляется не мгновенно).
3. **Коммит контракта** — с префиксом `api:` и регенерацией всех клиентов в том же изменении. CI (`contract.yml`) падает, если сгенерированный код не совпадает со спекой.
4. **Ошибки** — RFC 9457 (`Problem`), `Content-Type: application/problem+json`, поле `code` в snake_case для перевода на клиенте.
5. **Списки** — пагинация курсором (`cursor`, `limit`), фильтры в query, сортировка явная (`sort=field:asc`).
6. **Мутации с Android** несут заголовок `Idempotency-Key` (UUID операции); сервер хранит ключ и ответ 7 дней и на повтор отвечает тем же результатом. Появляется на этапе 1.
7. **Описания на русском**, идентификаторы (`operationId`, имена схем и полей) на английском.

## Структура

```
api/
├── openapi.yaml          # корень: info, servers, paths через $ref, components.schemas
├── paths/<module>.yaml   # операции одного модуля
└── components/*.yaml     # общие схемы (Problem, пагинация, …)
```

## Команды

```bash
task api:lint   # проверить спеку (redocly)
task gen        # перегенерировать сервер и клиентов
```
